# Data Engineering Task

This repository contains my Data Engineering projects completed as part of the
InternCareerPath Data Engineering Internship Program.

## Projects

### 1. API Data Ingestion

A Python-based data ingestion pipeline that extracts product data from a REST API
and loads it into PostgreSQL.

Key topics:

- REST API integration
- Pagination handling
- Data validation and transformation
- Incremental loading
- Error recovery and retry mechanism
- Pipeline state tracking
- Unit testing with Pytest

📁 Project folder: `api-data-ingestion`

📄 The project documentation is available inside the project folder.

---

### 2. ETL Pipeline CSV to Database

An ETL pipeline that processes raw CSV data and loads the transformed data into
a PostgreSQL database.

Key topics:

- CSV data extraction using Pandas
- Data validation
- Data transformation
- Data cleaning
- PostgreSQL data loading
- ETL pipeline orchestration
- Unit testing with Pytest

📁 Project folder: `etl-pipeline-csv-database`

📄 The project documentation is available inside the project folder.
